# 독후감

책 한 권을 여러 번 나눠 읽을 때, 읽을 때마다 독후감을 조금씩 써 두고
다 읽으면 Claude로 한 편의 독후감으로 엮는 아이폰용 웹앱(PWA).

- 책장: 표지 · 제목 · 읽기 시작한 날 ~ 다 읽은 날
- 책을 누르면 회차별 독후감 목록, `+` 로 추가 (날짜 · 읽은 범위 · 읽은 시간 · 내용 · 기억하고 싶은 문장)
- 🏁 마지막 독후감에 체크 → 그 날이 다 읽은 날, 요약 독후감 만들기
  - **요청 복사** → **Claude 열기** → 붙여넣고 보내기 → 결과를 앱에 붙여넣고 저장

## 표지 검색
카카오(키 있을 때) → Google Books → Open Library 순서로 찾음.
키 없는 Google Books는 전 세계가 같이 쓰는 한도라 자주 막혀서, 한국 책은 카카오 키를 추천.

카카오 키 받기: developers.kakao.com → 내 애플리케이션 → 앱 추가 → **REST API 키** 복사
→ 앱 설정 › 플랫폼 › Web 에 `https://imysss.github.io` 등록 → 앱 ⋯ › 🔑 표지 검색 설정에 붙여넣기.

## 데이터
폰(브라우저) 안에만 저장. ⋯ › 백업 파일 저장으로 가끔 내보내 두기.
키는 백업 파일에 들어가지 않음.

## 올리기
GitHub Pages로 배포 → 아이폰 Safari에서 열고 공유 › 홈 화면에 추가.
파일을 고치면 `sw.js`의 `VERSION`을 올려야 폰에 새 버전이 반영됨.
